# Exercícios de Python — Turma B Noturno

Coleção de 50 exercícios de lógica de programação resolvidos em Python, cobrindo desde conceitos básicos (entrada e saída, condicionais, laços de repetição) até estruturas de dados, funções, recursão e algoritmos clássicos.

Sobre

Este notebook foi desenvolvido como prática de fixação dos principais fundamentos da linguagem Python: variáveis, tipos de dados, estruturas condicionais, laços for e while, funções, listas, dicionários e manipulação de strings.

Cada exercício contém:

O enunciado do problema
O código da solução
Uma explicação de como a lógica foi construída
A saída de um teste executado
Como executar

O notebook foi feito para rodar no Google Colab, mas também funciona em qualquer ambiente Jupyter com Python 3.

Abra o arquivo .ipynb no Google Colab ou no Jupyter Notebook.
Execute as células em ordem (Ambiente de execução → Executar tudo).
Alguns exercícios pedem entrada de dados via input() — preencha os valores solicitados quando a célula pausar aguardando digitação.
